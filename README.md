# 🐹 Heaven (เฮเว่น) - น้องแฮมสเตอร์ออนไลน์ Real-time

เว็บแอปพลิเคชันเกมจำลองเลี้ยงน้องแฮมสเตอร์สีขาวสุดน่ารัก **"น้องเฮเว่น (Heaven)"** พัฒนาด้วย React (Vite), Tailwind CSS, Lucide React และเชื่อมต่อกับ **Firebase Realtime Database** ซิงก์ข้อมูลระหว่างผู้เล่นและแอดมิน (GM) แบบสดๆ 100%

---

## ✨ ฟีเจอร์เด่น (Key Features)

### 1. หน้าจอผู้เล่น (`/`)
- 🎨 **สไตล์เกมมือถือ Mobile-first**: โทนสีพาสเทลอบอุ่น อนิเมชันดุ๊กดิ๊กน่ารัก มีเสียงประกอบ Sound FX (Web Audio API สังเคราะห์ ไม่ต้องโหลดไฟล์เสียงเพิ่ม)
- 🐹 **ตัวละครน้องเฮเว่น (Pixel Art Fluffy Hamster)**: 
  - ท่าทางเปลี่ยนตามสถานะ: ปกติ, กินอาหาร, นอนหลับ, สกปรก/มอมแมม, ดีใจ, ลูบหัว
  - ระบบใส่ชุดและเครื่องประดับซ้อนเลเยอร์ (Layered Accessories): หมวกกบ, แว่นกันแดด, มงกุฎดอกไม้, โบว์แดง, ปลอกคอกระดิ่ง, ชุดฮู้ดดี้พิเศษ (Special Pastel Hoodie), ผ้ากันเปื้อน ฯลฯ
- 📊 **4 แถบสถานะลดลงตามเวลาจริง**: ความหิว (Hunger), ความสุข (Happiness), ความสะอาด (Cleanliness), พลังงาน (Energy)
- 🎮 **ระบบโต้ตอบหลัก**: ให้อาหาร, ลูบหัว (มีหัวใจลอย), เก็บอึในกรง (กดที่ก้อนอึได้โดยตรง), ปิดไฟให้นอนหลับ (ฟื้นฟู Energy)
- ⭐ **ระบบ Level, EXP และเหรียญเมล็ดทานตะวัน**:
  - **Lv.1**: เลี้ยงพื้นฐาน ให้อาหารเม็ดฟรี
  - **Lv.2**: ปลดล็อคมินิเกม **"ปั่นวงล้อ"** (รัวนิ้ว 10 วินาที เพื่อเก็บเหรียญและ EXP)
  - **Lv.3**: ปลดล็อค **"ร้านค้าอาหารพรีเมียม"** (เมล็ดทานตะวัน, บรอกโคลี, สตรอว์เบอร์รี, ชีสเค้ก)
  - **Lv.5**: ปลดล็อค **"ร้านค้าแฟชั่น & ตู้เสื้อผ้า"** (ซื้อและสลับใส่ชุดให้น้องได้ตลอดเวลา)
- 💬 **Speech Bubble & Pop-up กลางจอ**: แสดงคำสั่งเสียงสดๆ จาก GM แอดมิน
- 🌧️ **Event ฝนเมล็ดทานตะวัน**: เมล็ดทานตะวันโปรยปรายทั่วหน้าจอ ให้ผู้เล่นกดแตะเพื่อเก็บเหรียญฟรี (+5 เหรียญต่อเมล็ด)

### 2. แผงควบคุม GM แอดมิน (`/admin`)
- 🔐 **ระบบล็อกอินด้วยรหัสผ่าน**: รหัสผ่านเริ่มต้นคือ `1234`
- 📈 **Real-time Mirror Dashboard**: ดูกรงของน้องเฮเว่นแบบสดๆ เลเวล, EXP, เหรียญ, ค่าพลังทั้ง 4 หลอด และชุดที่ใส่อยู่
- 👑 **คำสั่งสดของ GM**:
  - เปย์เหรียญ: `+100` หรือ `+1,000` เมล็ดทานตะวัน
  - เพิ่ม EXP: `+100 EXP` หรือกด **อัปเลเวลทันที**
  - **ฟื้นฟู 100% ทุกหลอด** (Heal All)
  - **แกล้งน้อง**: ลดความสะอาดเหลือ 20% และเสกอึ 3 ก้อนเต็มกรง
  - **ส่งไอเทมลับเข้าตู้เสื้อผ้า**: ส่ง "ชุดฮู้ดดี้พิเศษ" (Special Hoodie), แว่นกันแดด หรือผ้าคลุมฮีโร่ เข้าตู้เสื้อผ้าผู้เล่นพร้อม Pop-up แจ้งเตือน
  - **สั่งให้น้องเฮเว่นพูด**: พิมพ์ข้อความสด ส่งไปขึ้น Speech Bubble เหนือหัวน้องบนจอผู้เล่นทันที
  - **ส่ง Pop-up แจ้งเตือนพิเศษ**: แจ้งเตือนกลางจอผู้เล่นแบบ Real-time
  - **เปิด Event ฝนเมล็ดทานตะวัน**: เสกฝนเหรียญตกลงมาบนจอผู้เล่น

## 🛠️ วิธีติดตั้งและรันในเครื่อง (Local Development)

```bash
# 1. ติดตั้ง Dependencies (ทำไว้เรียบร้อยแล้ว)
npm install

# 2. รันเซิร์ฟเวอร์ทดสอบ
npm run dev
```

เปิดบราวเซอร์ไปที่:
- หน้าผู้เล่น: `http://localhost:5173/`
- หน้าแอดมิน: `http://localhost:5173/admin`

> 💡 **หมายเหตุโหมดออฟไลน์/ทดสอบ (Demo Sync):**  
> แม้ยังไม่ได้ใส่ Firebase Key ระบบก็สามารถทำงานและ **ซิงก์ข้อมูลระหว่าง 2 แท็บบราวเซอร์แบบ Real-time ทันที** ผ่าน BroadcastChannel API ทำให้ทดสอบเปิดหน้าผู้เล่นและหน้าแอดมินข้างๆ กันเพื่อทดลองคำสั่ง GM ได้อย่างลื่นไหล!

## 🔥 การตั้งค่า Firebase Realtime Database

### ขั้นตอนที่ 1: นำค่า Config มาใส่
เปิดไฟล์ `src/firebaseConfig.js` และใส่ค่า config จาก Firebase Console:

```javascript
const firebaseConfig = {
  apiKey: "AIzaSy...",
  authDomain: "your-project.firebaseapp.com",
  databaseURL: "https://your-project-default-rtdb.firebaseio.com",
  projectId: "your-project",
  storageBucket: "your-project.appspot.com",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abcdef"
};
```
*(หรือใส่ผ่านตัวแปร Environment ในไฟล์ `.env.local` ตามตัวอย่างใน `.env.example`)*

### ขั้นตอนที่ 2: ตั้งค่า Security Rules ใน Firebase Realtime Database
ไปที่ **Firebase Console** > **Build** > **Realtime Database** > แถบ **Rules** แล้วกำหนดสิทธิ์ให้อ่านและเขียนโหนด `heaven_game`:

```json
{
  "rules": {
    "heaven_game": {
      ".read": true,
      ".write": true
    }
  }
}
```

## 🚀 การ Deploy บน Vercel

โปรเจกต์นี้ตั้งค่าไฟล์ `vercel.json` สำหรับจัดการ SPA Routing (รองรับการ Refresh หน้า `/admin` โดยไม่ติด 404) ไว้เรียบร้อยแล้ว:

```json
{
  "rewrites": [
    {
      "source": "/(.*)",
      "destination": "/index.html"
    }
  ]
}
```

### วิธี Deploy:
1. อัปโหลดโค้ดขึ้น GitHub / GitLab / Bitbucket
2. ไปที่ [Vercel Dashboard](https://vercel.com) แล้วกด **New Project**
3. เลือก Repository นี้
4. ในช่อง **Environment Variables** ให้เพิ่มคีย์ Firebase (หากต้องการตั้งค่าผ่าน Vercel Env)
5. กด **Deploy** เว็บไซต์พร้อมใช้งานทันที!
